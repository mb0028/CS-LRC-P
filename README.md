# CS-LRC-P
C# LRC Parser that I used in my game [Tree of Life](https://github.com/mb0028/Tree-of-Life) and [Gleamy LRC](https://github.com/mb0028/Gleamy-LRC) app.

- Load, Edit & Save lyrics from .lrc & .txt files
- Get current lyric line in real-time by audio position
